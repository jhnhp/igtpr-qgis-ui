# IGT-PR QGIS UI Prototype

Private repository for the IGT-PR QGIS plugin UI prototype.

## Current files
- `index.html` — interactive operator UI prototype with Beranda, IGT Utama tabs (Berbasis Bidang/Berbasis Kawasan), Load Baseline action, Upload Data actions, IGT Derivatif overview, and Model Builder placeholder.

## Important
This is a UI prototype only. Baseline loading, file uploads, validation, geoprocessing, and backend persistence are not connected to production QGIS services. Sample counts and records are illustrative.

The earlier multi-page prototype archive (`IGTPR-QGIS-updated-v3.zip`) is not yet committed as a binary archive; this repository currently contains a standalone interactive `index.html` implementation.
